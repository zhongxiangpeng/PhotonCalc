# 微波光子计算器 · 公式与换算关系审计报告

审计日期:2026-09-13
审计对象:`app/src/main/java/com/photoncalc/app/core/`(Kotlin 引擎)与 `prototype.html`(网页原型引擎)
审计方法:①逐条对照教科书/标准给出公式出处;②标准测试向量断言——Kotlin 侧 33 项单元测试(JUnit),HTML 侧用 node 直接执行页面真实引擎代码 74 项断言(`tools/audit.js`),双实现覆盖同一向量组交叉验证。
结果:**全部通过**(Kotlin 33/33,HTML 74/74)。审计过程中发现并已修正的问题见文末。

## 1. 功率与电平

| 关系 | 实现公式 | 出处/依据 |
|------|----------|-----------|
| dBm | P(dBm) = 10·lg(P / 1 mW) | 对数单位标准定义(IEC 60027-3) |
| dBW | dBW = dBm − 30 | 以 1 W 为参考的定义 |
| 反算 | P(W) = 10^(dBm/10) / 1000 | 同上 |

验证:0 dBm = 1 mW;30 dBm = 1 W;10 dBm = 10 mW;−30 dBm = 1 μW;往返闭合 < 1e-12。

## 2. 电压与功率(依赖系统阻抗 Z)

| 关系 | 实现公式 | 出处/依据 |
|------|----------|-----------|
| 功率-电压 | P = V²rms / Z | 欧姆定律(RMS 语义) |
| 峰峰-有效 | Vpp = 2√2 · Vrms | 正弦信号定义 |
| dBV | 20·lg(Vrms / 1 V) | 电压类 20lg 约定 |
| dBμV | dBV + 120 | 1 V = 10⁶ μV |
| 跨族 | 0 dBm @ 50 Ω = 223.607 mVrms = 632.456 mVpp = +106.99 dBμV | 数值核对 |

验证:10 dBm @ 50 Ω = 707.1 mVrms = 2 Vpp(工程常用数);0 dBm @ 75 Ω = 273.861 mVrms;九单位 3 种阻抗 × 往返闭合全部 < 1e-9。

**注意点(界面已标注)**:dBV/dBμV 本身是纯电压比、与阻抗无关;但它们与 dBm 互算必须经过 Z,App 内换算严格走 W→V→W 桥接。

## 3. 增益 / 衰减

| 关系 | 实现公式 | 出处 |
|------|----------|------|
| 功率类 | P_out(dBm) = P_in(dBm) + G(dB),即 10lg | 功率比 10lg |
| 电压类 | V_out = V_in · 10^(G/20),即 20lg | 电压比 20lg(同阻抗系统下与功率口径一致) |

验证:+6 dB ↔ ×1.9953(电压);−3.0103 dB ↔ 功率减半;级联逐级累加。

## 4. 热噪声底(kTB)

| 关系 | 实现公式 | 出处 |
|------|----------|------|
| 谱密度 | N₀ = 10·lg(k·T·10³) dBm/Hz,k = 1.380649×10⁻²³ J/K | 玻尔兹曼常数(SI 2019 定义值) |
| 积分 | N(dBm) = N₀ + NF + 10·lg(B/Hz) | 级联噪声系数口径(单级) |

验证:290 K → −173.98 dBm/Hz(工程常数 −174);290 K + 1 GHz + NF 3 dB → −80.98 dBm。
说明(界面已标注):含光放大器系统的 ASE 噪声另行计算,本卡仅电域热噪。

## 5. 光放大器 ASE 与 OSNR

| 关系 | 实现公式 | 出处/依据 |
|------|----------|-----------|
| ASE 谱密度 | ρ_ASE = NF·hν·(G−1)(W/Hz,双偏振) | Agrawal《Fiber-Optic Communication Systems》ch.6;NF ≈ 2n_sp 放大器噪声系数定义 |
| 光子谱密度 | hν @1550 nm = −158.92 dBm/Hz | E = hν,SI 基本常数 |
| 积分 | P_ASE(dBm) = 10·lg(ρ_ASE·B·10³) | 带宽内积分 |
| OSNR | OSNR = P_sig − P_ASE(同一带宽,dB) | ITU-T 关于 OSNR 的同参考带宽口径 |

验证:1550 nm、G=20 dB、NF=5 dB、B=0.1 nm(12.4784 GHz)→ P_ASE = −33.0 dBm,与经验速算 G + NF − 58 一致;G=0 dB → ASE=0(物理自洽)。

## 6. 传输线反射与阻抗匹配

| 关系 | 实现公式 | 出处 |
|------|----------|------|
| 反射系数 | Γ = (Z_L − Z₀)/(Z_L + Z₀),复数除法逐项展开 | Pozar《Microwave Engineering》ch.2 |
| 驻波比 | VSWR = (1+\|Γ\|)/(1−\|Γ\|);\|Γ\|≥1 时无定义(显示 —) | 同上 |
| 回波损耗 | RL = −20·lg\|Γ\| | 同上 |
| 失配损耗 | ML = −10·lg(1−\|Γ\|²) | 同上 |
| 串→并 | Q = \|X_s/R_s\|;R_p = R_s(1+Q²),X_p = X_s(1+Q²)/Q(与 X_s 同号) | 射频匹配网络 Q 变换标准结果 |

验证:75 Ω 接 50 Ω → Γ=0.2、VSWR=1.5、RL=13.9794 dB、ML=0.17729 dB、反射 4%;匹配 ZL=Z₀ → Γ=0、VSWR=1;纯电抗 ZL=j50 → |Γ|=1、VSWR 无定义;1+j1 ↔ 2∥j2 等效性闭合 1e-12。

## 7. 波长 / 频率 / 间隔

| 关系 | 实现公式 | 出处/依据 |
|------|----------|-----------|
| 波长-频率 | f = c/λ,c = 299 792 458 m/s(真空,SI 定义值) | SI |
| 间隔小量 | Δf = c·Δλ/λ²(及反推) | DWDM 信道间隔惯用换算(ITU-T G.694.1 背景口径) |
| 光子能量 | E(eV) = hc/λ / e | SI |

验证:1550 nm → 193.4145 THz、0.800 eV;Δλ=1 nm @1550 nm → 124.784 GHz;@1310 nm → 174.717 GHz;往返闭合 1e-15。

## 8. 马赫-曾德尔调制器

| 关系 | 实现公式 | 出处 |
|------|----------|------|
| 传输函数 | T = cos²(πV / 2Vπ) | MZI 双臂干涉,半波电压定义(V=Vπ 时 T: 1→0) |
| 正交偏置 | V_bias = Vπ / 2 | T=1/2 之解 |
| 小信号调制深度 | m = π·V_pk / Vπ(正交点线性化 dT/dV) | Q 点斜率 |Γ|=1 推导 |
| 相位摆幅 | Δφ_pp = π·Vpp/Vπ | 相移定义 |
| 推挽 | 等效 Vπ 减半(差分驱动约定) | 商用 LiNbO₃ 器件手册惯例 |

验证:V=0 → T=1;V=Vπ → T=0(此处审计曾抓到缺因子 2 的实现 bug,已修复并加入回归测试);Vpp=2、Vπ=4 → m=π/4≈0.785。

## 9. 光电探测

| 关系 | 实现公式 | 出处 |
|------|----------|------|
| 光电流 | I = R·P,R 为响应度(A/W) | 响应度定义 |
| 负载电压 | V = I·Z | 欧姆定律 |

验证:0 dBm 光、R=0.85 A/W → 0.85 mA;50 Ω 负载 → 42.5 mV。界面已注明为直流/平均量,交流小信号另经链路增益折算。

## 审计过程中发现并已修正的问题

1. **MZM 传输函数缺因子 2**(T 误写为 cos²(πV/Vπ)):单元测试抓到,已改为 cos²(πV/2Vπ) 并回归。
2. **1550 nm 频率速记**:精确值 193.4145 THz,早期文案写 193.5,已更正为 ≈193.4。
3. 审计脚本自身 4 处期望值/对照对象笔误(107 dBμV 换算、纯电抗用例负载取值、串并联对照写错),逐一核对标准值后修正——引擎本身无错。

## 结论

- 全部 9 组换算关系与教科书/标准一致,双实现(Kotlin/JavaScript)在相同测试向量下结果一致;
- 输入防呆:非数、零/负阻抗、|Γ|≥1、空输入均有兜底显示;
- 遗留说明:级联与换算假设同一阻抗系统;ASE 采用 NF 口径的双偏振公式;Δλ↔Δf 为小量近似(Δλ/λ ≪ 1 恒成立)。
